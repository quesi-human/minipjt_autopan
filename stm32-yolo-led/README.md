# YOLO → STM32 전달

실제 STM32 펌웨어는 [`../test_1/Src/main.c`](../test_1/Src/main.c)에 있습니다. [루트 README](../README.md)의 빌드·업로드·배선·실행 절차를 사용합니다.

`bridge.py`는 100ms마다 YOLO `/status`를 조회해 인원수를 USB 가상 시리얼로 전송합니다. 기본 포트는 `/dev/ttyACM0`이며 `--port`로 변경할 수 있습니다. `--display binary`를 지정하면 D7·D6·D5·D4를 8·4·2·1 자리로 표시하고, 15명 이상은 모두 켭니다. 기본 `bar` 모드는 인원수만큼 LED를 켜며 최대 4개입니다.

5바이트 패킷: `A5`, 표시 모드(0=bar, 1=binary), 인원수 하위 바이트, 인원수 상위 바이트, 앞 4바이트 XOR에 `5A`를 XOR한 검사 바이트. 인원수는 0~65535입니다. 정상 패킷에 대해 `ACK <인원수> <LED 비트 마스크>\n`을 응답합니다. 마스크 비트 0~3은 D4~D7입니다. `?` 한 바이트로 현재 인원수·마스크를 조회할 수 있습니다.

통신 중단 1초 후 STM32는 LED를 끕니다. HTTP 오류·흰 화면 경고·추론 결과 정지 시 브리지는 0명을 전달합니다. `bridge-status.json`은 매초 갱신됩니다. 현재 중점 x좌표는 HTTP API에서 제공하고 이 패킷에는 인원수만 포함합니다.
