# Third-party components

- YOLO11n pretrained weights (`esp32-usb-cam/models/yolo11n.pt`) and the Python inference dependency come from [Ultralytics](https://github.com/ultralytics/ultralytics). Refer to the upstream [license](https://github.com/ultralytics/ultralytics/blob/main/LICENSE) and model documentation for applicable terms.
- ESP32 firmware uses [Arduino-ESP32](https://github.com/espressif/arduino-esp32) and [esp32-camera](https://github.com/espressif/esp32-camera), installed through the ESP32 board package.
- STM32 startup, system support and CMake files were generated by STM32CubeIDE for Visual Studio Code. Original copyright and license notices are retained in those files.
- Python dependencies are declared in `esp32-usb-cam/requirements*.txt`; installed package directories are not included.
